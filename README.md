# Tugas 4 — Arunika Studio

## Deskripsi
Arunika Studio merupakan website studio kreatif yang dibuat menggunakan HTML dan CSS. Website ini menampilkan informasi studio, layanan desain, dan kontak.

## Perubahan Website
Pada tugas ini, saya memperbaiki tampilan website agar lebih rapi dan nyaman dilihat. Saya menyesuaikan perpaduan warna, tata letak elemen, serta tampilan bagian layanan. Selain itu, website dibuat responsif agar dapat menyesuaikan ukuran layar PC maupun perangkat mobile.

## Teknologi
- HTML untuk struktur halaman.
- CSS untuk mengatur tampilan dan tata letak.
