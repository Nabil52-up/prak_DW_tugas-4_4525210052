# Tugas 4 — Arunika Studio

## Deskripsi
Arunika Studio merupakan website studio kreatif yang dibuat menggunakan HTML dan CSS. Website ini menampilkan informasi studio, layanan desain, dan kontak.

## Ringkasan Perubahan Arunika Studio

Pada tugas ini, saya mengubah tampilan website Arunika Studio agar terlihat lebih rapi dan nyaman digunakan. Website ini memiliki beberapa bagian, yaitu header, hero, tentang kami, layanan, kontak, dan footer. Saya juga mengubah warna tampilan menjadi hijau, krem, dan putih agar terlihat lebih menarik.

Saya memisahkan kode HTML dan CSS ke dalam dua file yang berbeda, yaitu `index.html` dan `style.css`. Saya juga menggunakan beberapa class yang bisa dipakai kembali pada bagian lain website agar kode lebih mudah diatur.

Saat mengerjakan tugas ini, saya menemukan bahwa tampilan kartu layanan pada layar kecil masih kurang sesuai. Oleh karena itu, saya mengubah susunan kartu agar menjadi satu kolom saat dibuka melalui HP. Saya juga menyesuaikan bagian header dan hero supaya tampilannya tetap rapi pada layar yang lebih kecil.

Selain itu, saya menggunakan `box-sizing: border-box` untuk membantu mengatur ukuran elemen dan menambahkan media query agar tampilan website bisa menyesuaikan ukuran layar.

Dengan perubahan ini, website Arunika Studio menjadi lebih teratur dan lebih nyaman dilihat, baik melalui komputer maupun HP.

## Teknologi
- HTML untuk struktur halaman.
- CSS untuk mengatur tampilan dan tata letak.
